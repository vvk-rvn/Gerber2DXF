# Gerber → DXF

Конвертер Gerber (RS-274X / X2) и сверловки Excellon в DXF (миллиметры) — с окном и из командной строки.

Понимает архивы **JLCPCB / JLC CAM** (`bl`, `tl`, `bo`, `to`, `bs`, `ts`, `drl`, `ko`, `vcut`, `sk`…) и **KiCad** (`*.gbr` + `PTH/NPTH.drl`), в том числе вложенные zip.

## Запуск

### Windows — готовая программа

`Gerber2DXF.exe` (Python не нужен; собирается командой `build_exe.bat`, см. ниже).

1. Запустите `Gerber2DXF.exe` (или перетащите zip-архив на значок).
2. **Zip…** — выберите архив Gerber (или **Папка…** — распакованную папку).
3. Папка вывода подставится сама: `<имя архива>_dxf` рядом с архивом.
4. Дальше на выбор:
   - **Превью слоёв…** — открыть окно просмотра, выбрать слои галочками и сохранить в DXF только их;
   - **Конвертировать всё** — сразу записать все слои → **Открыть папку вывода**.

### Окно превью

- Все слои набора на одном холсте в цветах, привычных по редакторам плат (медь верх — красная, низ — синяя, маска — зелёный контур, шелкография — белая, отверстия — голубые, контур платы — жёлтый).
- Галочка у слоя — показать / скрыть; **Все слои** / **Ни одного** — разом.
- Колесо мыши — масштаб относительно курсора, перетаскивание — сдвиг, двойной клик или **Вписать** — показать все отмеченные слои целиком. Внизу — координаты курсора в мм.
- Если в архиве несколько наборов (например, панель JLC и исходники KiCad), они переключаются списком **Набор**.
- **Сохранить DXF (отмеченные слои)** — записывает только видимые слои текущего набора; формат вывода (по слоям / общий файл) берётся из галочек главного окна.

> При первом запуске Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

### Python (Windows / Linux / macOS)

```bash
python -m pip install -r requirements.txt

python gerber2dxf.py                         # окно программы
python gerber2dxf.py input.zip               # вывод в input_dxf/
python gerber2dxf.py input.zip -o out_dir    # своя папка вывода
python gerber2dxf.py a.zip b.zip -o out_dir  # несколько архивов
```

| Ключ | Действие |
|---|---|
| `-o`, `--output` | папка вывода (по умолчанию `<вход>_dxf` рядом со входом) |
| `--no-layers` | не писать отдельные DXF по слоям |
| `--no-combined` | не писать `ALL_LAYERS.dxf` |

Тот же консольный режим есть у exe: `Gerber2DXF.exe input.zip -o out_dir` (без окна, журнал — `gerber2dxf_log.txt` в папке вывода).

## Результат

Для каждого набора Gerber в архиве создаётся своя подпапка:

- `<слой>.dxf` — каждый слой отдельным файлом;
- `ALL_LAYERS.dxf` — все слои в одном файле, DXF-слой = имя слоя.

| Gerber | DXF |
|---|---|
| дорожки | `LWPOLYLINE` по оси, ширина = толщина дорожки (многие CAD/лазерные программы показывают только ось) |
| площадки | `CIRCLE` / замкнутые контуры реальной формы, включая макро-апертуры |
| полигоны (G36/G37) | замкнутые контуры |
| отверстия / пазы | `CIRCLE` диаметром сверла / контур овала |
| негативные объекты (`%LPC%`) | отдельный слой `<имя>_CLEAR` (вычитание в DXF невозможно) |

Слои JLC: `tl`/`bl` — медь верх/низ, `to`/`bo` — шелкография, `ts`/`bs` — паяльная маска, `drl` — сверловка, `ko` — контур платы, `vcut` — линии V-скрайбирования, `sk` — закрытие переходных отверстий.

## Сборка exe

```bat
build_exe.bat
```

Нужны Python 3.8+, `ezdxf` и `pyinstaller`. Результат — `dist\Gerber2DXF.exe` (один файл, ~27 МБ).

## Ограничения

- Step & Repeat (`%SR%`) и блочные апертуры (`%AB%`) не раскрываются — в журнале будет предупреждение.
- Термальный макро-примитив (7) рисуется двумя окружностями.
- Скруглённые площадки KiCad (`RoundRect`) состоят из нескольких перекрывающихся контуров — так они описаны в самом Gerber.
- Координат компонентов в Gerber нет — файл размещения выгружается из KiCad (`.pos`).
